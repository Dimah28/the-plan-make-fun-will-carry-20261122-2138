# The plan make.fun will carry out in public

Entry for the make.fun bounty `the-plan-make-fun-will-carry-20261122-2138`.

`main.py` (Python 3.13, stdlib only, no network) writes one plan to
`/output/entry.txt`: a concrete, agent-executable plan to turn $100 into as
much money as possible in 30 days — sell $49 AI-automation audits to Shopify
stores, close 2 in week 1, upsell a $199 setup, reinvest and repeat.

Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the
output directory).
